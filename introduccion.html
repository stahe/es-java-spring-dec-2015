    1. Introducción

    1.1. Antecedentes

    Este documento sirve tanto como clase magistral como tutorial universitario (TD). Está dirigido a principiantes. Utiliza las siguientes fuentes:

    Referencias:

    1. Introducción al lenguaje Java;
    2. Trabajo con una base de datos relacional utilizando el ecosistema Spring;

    Nos referiremos a estas fuentes como [ref1] y [ref2], respectivamente. La fuente [ref1] está desactualizada (2002), pero es suficiente para este documento, donde se utiliza únicamente para la presentación de la sintaxis del lenguaje Java y las operaciones básicas. El resto del material necesario para completar el trabajo se presenta en este documento en los capítulos titulados [Curso]. Estos capítulos se han extraído directamente de [ref2] (2015) y se han simplificado en algunos casos.

    El objetivo de este documento es enseñar el lenguaje Java desde una perspectiva profesional. Por este motivo, nos basamos en gran medida en el marco Spring [http://spring.io/], que se utiliza ampliamente en el desarrollo de JEE (Java Enterprise Edition). Lógicamente, este curso debería ir seguido de un curso de JEE. Este es el caso en Istia (Universidad de Angers). JEE es actualmente (noviembre de 2015) la principal fuente de empleo para los jóvenes desarrolladores con un máster. Existen muchas otras tecnologías además de Spring en el mundo JEE. Spring tiene la ventaja de ser fácil de entender y, sobre todo, de proporcionar buenas prácticas de programación que pueden reutilizarse fuera del ecosistema Spring. Esto explica por qué se ha elegido aquí.

    Este laboratorio lleva más de 10 años en uso y ha evolucionado con las tecnologías. Va seguido (en IstiA) de un laboratorio de JEE [Introducción a Java EE]. Este último laboratorio data de 2012 (ahora estamos en 2015) y le vendría bien una actualización. Presenta el estándar JEE a través del marco web JSF2 (Java Server Faces) y EJB3 (Enterprise Java Bean). En conjunto, estos dos tutoriales han permitido a muchos estudiantes conseguir prácticas de JEE en empresas de servicios digitales (ESN) y ser contratados allí inmediatamente después.

    En este documento no encontrarás una presentación formal de todos los aspectos de Java. A lo largo de los años, la forma en que los desarrolladores junior abordan un problema ha cambiado significativamente. Hoy en día, casi siempre recurren a Internet para encontrar fragmentos de código que, al juntarlos, forman un programa. Si les proporcionamos un curso, lo utilizan muy poco y prefieren volver a Internet. Aunque al principio era escéptico respecto a este enfoque, me sorprendieron los resultados. Los alumnos con dificultades fueron capaces de crear programas que funcionaban, mientras que sin la ayuda de Internet probablemente no lo habrían conseguido. Ahora confío en este enfoque.

    Los fragmentos de código no ofrecen una visión general de la arquitectura de una solución, y uno de los objetivos de este documento es proporcionar esa visión general. Los alumnos completan este tutorial como un ejercicio de laboratorio, trabajando de forma independiente. No hay clase magistral. Existe un calendario que describe el progreso que se espera de ellos a lo largo de las sesiones. Pueden ir por detrás o por delante de este calendario. Su progreso se verifica a través de una serie de puntos de control que deben presentar al instructor. El instructor está presente tanto para dar explicaciones cuando se le solicitan como para validar su trabajo. Cada uno trabaja a su propio ritmo. Al final de las 36 horas asignadas a este laboratorio, algunos habrán completado un 50 % más de validaciones que otros, pero todos —al menos ese es el objetivo— habrán comprendido lo que hicieron por sí mismos. Este laboratorio puede completarse sin la orientación de un profesor. Por eso está disponible en [https://stahe.github.io].

    Este documento no es adecuado para quienes buscan un curso académico sobre Java, es decir, algo que explique Java de forma estructurada y paso a paso, donde se explique y justifique cada detalle de la sintaxis. Más bien, lo que se propone aquí es un enfoque experimental. Es probable que el alumno no comprenda todo lo que se presenta en el documento, pero seguramente podrá sacar partido a su contenido, y la comprensión de los detalles vendrá con la experiencia.

    Este documento tampoco es un curso sobre algoritmos. El algoritmo del ejercicio es básico y puede ser resuelto por cualquier principiante que esté cursando sus primeras asignaturas de algoritmos. El documento se centra en el entorno de desarrollo profesional de Java, con sus numerosas bibliotecas y marcos de trabajo, así como en la arquitectura del código. La mayoría de los estudiantes que veo tienen carencias en algoritmos, lo cual confirman posteriormente sus supervisores de prácticas. Así que sí, el dominio de los algoritmos es importante, pero no es el objetivo principal de este tutorial.

    Por último, este documento (diciembre de 2015) no cubre las últimas características de Java, en particular los flujos y las funciones lambda. Sin embargo, sí utiliza algunos elementos del último JDK, el JDK 1.8, y el código que sigue debe compilarse utilizando este JDK.

    1.2. Contenido

    El capítulo 2 presenta el tema del tutorial: el cálculo de los resultados electorales. El problema es sencillo. El capítulo 2 te pide que implementes la solución utilizando dos lenguajes muy similares, C# y Java. La implementación se realiza sin clases. El objetivo es presentar la sintaxis de Java, sus sentencias básicas y el IDE (entorno de desarrollo integrado) Eclipse, utilizado para crear proyectos Java.

    El capítulo 3 te pide que implementes la solución del ejercicio en Java utilizando clases. El objetivo es presentar los conceptos de clases, herencia, interfaces y clases genéricas. Se introduce el concepto de pruebas unitarias con JUnit.

    El capítulo 4 presenta los conceptos subyacentes a los siguientes capítulos:

    • arquitecturas por capas;
    • programación por interfaces;
    • el uso de Spring para implementar los dos conceptos anteriores;

    1.3. Herramientas utilizadas

    Los siguientes ejemplos se han probado en el siguiente entorno:

    • Equipo con Windows 10 Pro de 64 bits;
    • JDK 1.8 (Sección 22.1);
    • Spring Tool Suite 3.6.3 IDE (Sección 1);
    • NetBeans 8.1 (sección 22.4);
    • Navegador Chrome (no se utilizaron otros navegadores);
    • Extensión de Chrome [Advanced Rest Client] (sección 1);
    • WampServer, que incluye el SGBD MySQL y la herramienta [PhpMyAdmin] para gestionarlo (sección 22.7);

    Es importante utilizar JDK 1.8. Algunos ejemplos utilizan componentes de este JDK. La mayoría de los ejemplos son proyectos Maven que se pueden abrir con cualquiera de los siguientes IDE: Eclipse [https://www.eclipse.org/], IntelliJ IDEA Community Edition [https://www.jetbrains.com/idea/download/] y NetBeans [https://netbeans.org/]. A continuación, las capturas de pantalla proceden del IDE Spring Tool Suite, una variante de Eclipse.

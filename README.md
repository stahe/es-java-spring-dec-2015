## 📚 Acerca de este documento

Este material didáctico está destinado a estudiantes principiantes en el ámbito universitario. Combina conceptos teóricos del curso con ejercicios prácticos.

### Objetivos de aprendizaje

El objetivo principal es enseñar el lenguaje Java desde una perspectiva **profesional**. Por este motivo, el curso se basa en gran medida en el marco **[Spring](http://spring.io/)**, una tecnología utilizada en el desarrollo **JEE** (Java Enterprise Edition).

Lógicamente, este módulo sirve como introducción previa a la realización de un curso especializado en JEE.
